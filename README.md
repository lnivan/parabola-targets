# Parabola Targets

A Pygame projectile puzzle: aim parabolic shots around obstacles to hit targets.

![Project preview](docs/preview.png)

## What it contains

- Drag to set a projectile's initial velocity.
- Obstacles, moving targets and level progression.
- Five implemented level functions and the original bitmap assets.

## Setup

Use Python 3.12. From the repository folder:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Controls

Choose the first unlocked level. Press in the left launch area, drag backwards and release to launch.

## Project status

The original menu includes placeholders beyond the five implemented levels. Progress is kept for the current session.
